# 记账本 App - 新手部署指南

## 一、你需要准备的工具

| 工具 | 用途 | 下载地址 |
|------|------|----------|
| **HBuilderX** | 开发工具（写代码+打包APK） | https://www.dcloud.io/hbuilderx.html |
| **安卓手机** | 安装和测试App | 你已有 |
| **DCloud 账号** | 云打包需要 | 注册地址 https://dev.dcloud.net.cn |

> 不需要安装 Android Studio、不需要配置 Java 环境、不需要装 Git。HBuilderX 一站搞定。

---

## 二、安装 HBuilderX（第1步）

1. 打开 https://www.dcloud.io/hbuilderx.html
2. 下载 **Windows 正式版**（选「App开发版」，不是前端版）
3. 下载后是一个 zip 压缩包，解压到任意目录（比如 `D:\HBuilderX`）
4. 进入解压目录，双击 `HBuilderX.exe` 运行
5. 首次运行会提示登录，点击「注册」注册一个 DCloud 账号
6. 登录成功

---

## 三、导入项目（第2步）

1. 打开 HBuilderX
2. 菜单栏 → 文件 → 打开目录
3. 选择本项目文件夹 `bookkeeping-app`
4. 项目会出现在左侧项目管理器中
5. 展开项目，你应该能看到以下文件结构：

```
bookkeeping-app/
├── pages/
│   ├── index/index.vue        ← 首页（账单列表）
│   ├── add/index.vue          ← 记一笔
│   ├── statistics/index.vue   ← 统计图表
│   └── settings/index.vue     ← 设置
├── utils/
│   ├── db.js                  ← 数据库操作
│   ├── categories.js          ← 分类预设
│   └── format.js              ← 格式化工具
├── App.vue                    ← 应用入口
├── main.js                    ← JS入口
├── pages.json                 ← 页面配置
├── manifest.json              ← 应用配置
├── uni.scss                   ← 全局样式
└── package.json
```

---

## 四、在浏览器预览（第3步·可选）

先在电脑上看看效果，不用手机：

1. 菜单栏 → 运行 → 运行到浏览器 → Chrome
2. 等待编译完成（首次约10-20秒）
3. 浏览器自动打开，显示App界面
4. 按键盘 `F12` → 点击手机图标，切换为手机视图
5. 可以点击各页面、记账、查看统计图表

> 浏览器预览时数据保存在浏览器本地存储中，与手机端数据不共享。

---

## 五、打包成 APK 安装包（第4步·核心）

这一步把项目打包成可在安卓手机上安装的 APK 文件：

### 5.1 配置应用信息

1. 在 HBuilderX 中双击打开 `manifest.json`
2. 在可视化界面中确认以下配置：

| 配置项 | 推荐值 |
|--------|--------|
| 应用名称 | 记账本 |
| 应用描述 | 简单好用的个人记账本 |
| 版本号 | 1.0.0 |
| AppID | （自动生成，如未生成点击「重新获取」） |

3. 点击左侧「App模块配置」，勾选 **SQLite（SQLite数据库）**
   - 这一步非常重要！记账数据靠它存储

4. 点击左侧「App权限配置」，确认已勾选：
   - `android.permission.WRITE_EXTERNAL_STORAGE`（存储权限）

### 5.2 云打包（推荐新手使用）

1. 菜单栏 → 发行 → 原生App-云打包
2. 在弹窗中配置：

| 配置项 | 推荐值 |
|--------|--------|
| 安卓打包证书 | 选择「使用公共测试证书」（新手选这个） |
| 包名 | `com.mybook.app`（随意，格式正确即可） |
| Android 版本 | 5.0+（minSdkVersion 21） |
| CPU类型 | `armeabi-v7a` 和 `arm64-v8a` 都勾选 |
| 打包方式 | 使用云端证书（推荐） |

3. 点击「打包」按钮
4. 等待约 2-5 分钟（DCloud 云端服务器在编译）
5. 打包完成后，HBuilderX 底部控制台会显示：
   - APK 下载链接
   - 或者自动下载到 `unpackage/release/apk/` 目录

### 5.3 如果云打包失败

常见原因和解决方案：

| 问题 | 解决方案 |
|------|----------|
| AppID 为空 | manifest.json 中点击「重新获取」 |
| 未登录 DCloud | 右上角登录账号 |
| 打包超时 | 换个时间段重试（云端繁忙） |
| 证书错误 | 选择「使用公共测试证书」 |

## 六、安装到手机（第5步）

### 方式A：直接传输 APK（推荐）

1. 找到打包好的 APK 文件（后缀 `.apk`）
2. 用以下任意方式传到手机：
   - QQ/微信发送到「文件传输助手」
   - USB 数据线复制
   - 蓝牙传输
3. 在手机上点击 APK 文件安装
4. 如果提示「未知来源应用」，允许安装即可

### 方式B：HBuilderX 直连手机运行（调试用）

1. 手机开启「开发者选项」和「USB调试」
   - 设置 → 关于手机 → 连续点击7次「版本号」
   - 返回设置 → 系统 → 开发者选项 → 打开USB调试
2. USB 连接电脑和手机
3. HBuilderX 菜单 → 运行 → 运行到手机或模拟器 → 你的安卓设备
4. 手机上会自动安装并打开App

## 七、App 功能说明

### 首页（账单）
- 顶部蓝色卡片：显示当前月份的「收入」「支出」「结余」
- 月份切换：点击左右箭头查看不同月份
- 账单列表：按日期分组显示，每天显示当天支出小计
- 长按某条记录：弹出删除选项
- 右下角蓝色「+」按钮：记一笔

### 记一笔
- 支出/收入切换
- 金额输入（支持小数）
- 16个支出分类 + 7个收入分类（emoji图标）
- 备注（可选，最多100字）
- 日期选择（默认今天，可改历史日期）

### 统计
- 环形饼图：各分类占比
- 分类排行：按金额从多到少，带进度条
- 近6个月收支趋势柱状图

### 设置
- 导出账单数据（CSV格式）
- 清空所有数据（需二次确认）
- 版本信息、使用说明

---

## 八、数据存储说明

- 所有记账数据保存在**手机本地** SQLite 数据库
- 数据文件路径：`手机存储/Android/data/你的包名/files/_doc/book.db`
- 卸载App = 数据清除，请提前用「导出」功能备份
- 换手机需重新记账（无云同步功能）

---

## 九、后续扩展方向

如果你想继续完善这个App，可以考虑：

1. **预算设置** - 每月设定支出预算，超支提醒
2. **账单导出** - 已实现CSV导出，可扩展Excel格式
3. **数据备份恢复** - 导出/导入完整数据库文件
4. **自定义分类** - 允许用户添加自己的分类
5. **周报/年报** - 更长时间维度的统计分析
6. **云同步** - 接入后端服务器实现多设备同步（需学习后端开发）

---

## 十、遇到问题怎么办

| 问题 | 排查方法 |
|------|----------|
| App闪退 | 检查 manifest.json 是否勾选了 SQLite 模块 |
| 数据丢失 | SQLite 数据库文件路径是否正确，检查权限配置 |
| 打包失败 | 查看 HBuilderX 控制台错误信息，通常是配置问题 |
| 饼图不显示 | 确认本月有记账数据，且选对了收支类型 |
| 分类图标显示方块 | 部分安卓系统emoji支持不全，不影响功能 |
